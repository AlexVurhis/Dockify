# Dockify — Умная анимационная док-панель для Windows

Красивое, легкое и современное решение для организации вашего рабочего пространства. Полная свобода кастомизации интерфейса, живая физика эффектов и умный контроль ресурсов.

## 🦋 Главные особенности и функции

* **Живые эффекты:** Парящие неоновые светлячки или порхающие бабочки с мягкой физикой затухания прямо на заднем плане вашего дока.
* **Умная эргономика:** Добавление ярлыков обычным перетаскиванием файлов мыши (Drag-and-Drop), плавная живая сортировка и функция умного автоскрытия панели.
* **Режим «Заморозки»:** Мгновенная остановка всех ресурсоемких анимаций в один клик через контекстное меню для освобождения процессора под тяжелые игры или программы.
* **Безопасность кода:** Все файлы настроек изолированы в пользовательских Документах Windows, а сами инсталляторы надежно запечатаны цифровой подписью автора.
